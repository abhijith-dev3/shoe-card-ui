This project showcases a stylish shoe card featuring dynamic color switching, hover animations, and responsive design suitable for e-commerce websites or portfolio projects.

[Demo]()



Features

Dynamic Color Theme: Click on color options to instantly change the card’s theme.

Interactive Shoes: Shoes slide and rotate on color selection for a 3D-like effect.

Responsive Design: Scales properly on desktop and mobile screens.

Stylish Layout: Includes badge, price tag, star ratings, size selector, and color options.

Smooth Animations: Transitions for shoe movements and theme changes.

Tech Stack

HTML5 – Semantic structure.

CSS3 – Flexbox, Grid, transitions, hover effects.

JavaScript – Color theme toggle functionality.

Google Fonts: Quicksand.

FontAwesome: Star icons.
